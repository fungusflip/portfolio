This project, developed by a team of five over four weeks, marks my first experience with a full-time technical game slice. It was incredibly entertaining and sparked my love for collaboration, especially using Scrum as a tool. In the game, you play as Harmony the Druid, battling evil critters and mischievous spirits to heal a misguided forest. Watch the trailer or download the game to experience it for yourself! Enjoy! 😊

Development Process
  • Miro
    • System Planing,Pseudo code, Team documentation, Mindmaps.
  • Trello
    • Scrum Task management.
New Technical Knowledge
  1. Scrum Framework Implementation:
    • Employed Scrum framework for efficient team organization and project management.
  2. Shader Experimentation for Environment Changes:
    • Explored materials and GSL shaders to dynamically alter environmental elements.
  3. Observer Pattern for Readable Code:
    • Implemented the Observer pattern to enhance code clarity and maintainability.
  4. Scriptable Objects for Scalability:
    • Utilized Scriptable Objects to enhance project scalability and flexibility.
  5. State Machine for Quest Management:
    • Implemented a state machine system for managing quest states and progression.
